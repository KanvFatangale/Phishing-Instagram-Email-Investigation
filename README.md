 Phishing Email Investigation
	
    Objective :
		The objective of this project is to investigate a suspicious phishing email
		using email headers , URLs , attachments and threat intelligence .

    Scenario :
		A user received an email claiming that their Instagram account would be suspended unless they verified their  account
		immediately

    Tools Used
		-Email Header Analysis
		-VirusTotal
		-URl Analysis
		-GitHub

  Investigation Process
	
		1.Collected email headers
		2.Analyzed sender information
		3.Checked SPF ,DKIM and DMARC
		4.Investigated URLs
		5.Analyzed attachment
		6.Checked indicators using VirusTotal
		7.Extracted IOCs
		8.Classified the email
	
 Final Verdict :
 
		PHISHING

Key Findings

		-Suspicious Sender
		-Malicious URL reputation
		-Suspicious URL
		-Urgent language

 Skills Demonstrated
		- Email Analysis
		- Phishing Detection
		-IOC Extraction
		-Threat Intelligence
		-Incident Reporting
